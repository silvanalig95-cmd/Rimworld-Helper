# The order of everything (the portrait kit)

The steps, what each does, what you set up once and what the picture check can change are all in `GUIDE.md` now, kept up
to date with every change to the kit. The setup of each ComfyUI workflow is in `SETUP-ComfyUI.md`.

The short order of a round: Run-PortraitBatch, sort the output, Copy-ToLibrary (writes the records), Check-Pictures
(offers to write the records at the end), Review-Pictures (Done writes the records), Make-DepthMaps and Make-Variants
when wanted (both write the records), then "Reload the library" in the game.
